Frame Embed Demo

This player is a nested third-party iframe — allowed only because the manifest declares csp_overrides["frame-src"]: ["https://www.youtube-nocookie.com"]. Remove the declaration, republish, and the browser refuses the frame (DevTools: Refused to frame … frame-src).

Jump-to-timestamp rebuilds the embed URL with ?start=N&autoplay=1 — playback resumes only because autoplay is delegated (Permissions-Policy header → window iframe allow → this bundle's iframe allow). Local harness note: anna-app dev sets no CSP headers, so this works locally even without the manifest declaration — always verify against an online working draft.
